# 剧本杀小助手

给剧本杀玩家用的**线索整理笔记**：思维导图 + 卡片笔记 + 时间线，打本时随手记，结束后一键导出精美长图和永久离线存档，年底拿来做「年度剧本杀总结」。

- 在线使用：<https://lwd619783-byte.github.io/jubensha-helper/>
- 源码仓库：<https://github.com/lwd619783-byte/jubensha-helper>
- 纯前端、无账号、无服务器：所有数据只保存在你自己的浏览器里（IndexedDB）
- 打开过一次之后断网也能用；电脑、平板、手机（包括折叠屏）都有专门的布局

## 功能

- **导图**：自动排版的思维导图，卡片分 7 种类型（人物 / 线索 / 地点 / 事件 / 疑点 / 推理 / 笔记），可以拖拽挂接、折叠分支、用分区框住一组卡片
- **关系线**：在任意两张卡片之间拉线，带标签和样式（如「动机？」「依据」「时间冲突」）
- **速记（N）**：打本时最常用。一行就是一张卡片，`21:10` 开头自动记为事件时间，`@人名` 关联人物，`#标签` 加标签，截图可以直接粘贴
- **分视图**：线索、人物（嫌疑度）、时间线（按时间排序，生成「人物 × 时间」对照表并自动标出冲突）、疑点 & 待问、笔记、结案 & 复盘
- **搜索与命令（⌘/Ctrl + K）**：搜卡片、跳转、执行命令
- **导出**
  - 导图图片（PNG，高清，适合发朋友圈 / 做总结）
  - 离线存档（单个 .html 文件，图片都内嵌在里面，永久可打开、只读浏览，也能再导入回来继续编辑）
  - 数据备份（.json，用来换设备、电脑和手机之间同步）
- 浅色 / 深色主题，撤销 / 重做，自动保存

## 快捷键（电脑）

| 按键 | 作用 | 按键 | 作用 |
| --- | --- | --- | --- |
| `N` | 速记 | `⌘/Ctrl + K` | 搜索与命令 |
| `Tab` | 添加子卡片 | `Enter` | 添加同级卡片 |
| `Space` / `F2` | 编辑标题 | `1` – `7` | 切换卡片类型 |
| `L` | 从所选卡片拉连线 | `G` | 用分区框住所选 |
| `/` | 折叠 / 展开分支 | 方向键 | 在卡片间移动 |
| `Delete` | 删除所选 | `⌘/Ctrl + D` | 创建副本 |
| `⌘/Ctrl + Z` | 撤销（加 `Shift` 重做） | `⌘/Ctrl + 0` | 适应画布 |
| `I` | 查看详情 | `?` | 快捷键一览 |
| `Shift` + 拖动 | 框选 | 双击空白 | 新建卡片 |

## 手机 / 平板

- 底部标签栏切换导图、线索、人物、时间线；右下角 **＋** 打开速记
- 点卡片 → 弹出详情；长按卡片或空白处 → 菜单；单指拖动平移、双指缩放
- 建议在打本前先用浏览器打开一次网址，如果浏览器提示「添加到桌面 / 安装应用」就添加，之后断网也能打开

## 数据与备份

- 数据只存在当前设备的当前浏览器里，换浏览器、清除浏览器数据都会看不到。重要的局记得导出
- 每打完一局：导出「离线存档 .html」永久保存；需要在别的设备继续编辑就导出「数据备份 .json」，在另一台设备「数据与备份 → 导入」
- 导入时遇到同一个剧本，会询问「覆盖」还是「保留两份」
- 新设备初次打开会自动创建空白《离家出走》。导入备份后如果出现同名空白局，可在「本库」中手动删除空白局；不要误删有内容的一局。

## 部署到 GitHub Pages

仓库里已经包含构建好的 `index.html`，无需构建即可部署：

1. 打开仓库 **Settings → Pages**
2. Source 选 **Deploy from a branch**，Branch 选 `main`、目录 `/ (root)`，保存
3. 等一两分钟，访问 `https://<用户名>.github.io/<仓库名>/`

## 开发

建议使用 Node.js 20 或更新版本。交付包已将依赖固定为已测试版本，并附带 `package-lock.json`。

```bash
npm ci
npm run build   # 生成 index.html、剧本杀小助手.html、sw.js、manifest 和图标
```

- `src/`：React 源码（`app.jsx` 外壳、`board.jsx` 导图画布、`views.jsx` 各视图、`store.js` 状态、`db.js` 本地存储、`exporter.js` 导出）
- `index.html`：在线版（配合 `sw.js` 离线缓存，可安装为应用）
- `剧本杀小助手.html`：单文件离线版，双击即可在浏览器里使用（数据同样存在该浏览器里）

## 隐私

不收集任何数据，不联网同步，没有统计脚本。你记下的所有内容都只在你自己的设备上。
